INDIAN OUTBOUND TRAVEL ANALYTICS - R SHINY PROJECT
===================================================

HOW TO RUN
1. Install R and RStudio (or VS Code with the R extension).
2. Open this project folder.
3. Open app.R.
4. Run the file. In RStudio, click Run App.
5. The application will install missing R packages automatically the first time.

FILES
- app.R
- data/outbound_india_top15.csv
- data/outbound_india_totals.csv
- data/monthly_departures_2023_2024.csv

DATA SOURCE
Ministry of Tourism, Government of India.
India Tourism Data Compendium 2025, Table 3.1.3.
Underlying source: Bureau of Immigration (BOI), Government of India.

The country-level table covers the Top 15 destination countries for 2019, 2023 and 2024.
The monthly 2023/2024 data comes from the Ministry of Tourism Annual Report 2024-25.

IMPORTANT
The map uses approximate country-centre coordinates only for visualization. They do not represent
specific departure airports or ports.
